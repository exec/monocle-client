# Independent highway restocking

New assignments negotiate the independent-restock capability before native preparation; mixed unsupported crews are refused. Only the requesting worker detaches. Remaining builders cover its duties without regrouping or resetting block confirmations.

Placed containers are protected observations rather than a global mutex. Owners retain cleanup responsibility, and fresh observations survive cancellation and recovery. Native restocking owns outbound travel, opening, transfer and cleanup before return travel begins.

Returners follow visible active crewmates or a fresh revision-matched host front, never an old supply waypoint. All-detached crews use the verified checkpoint. A disconnected supplier or individually failed workflow does not stop unrelated builders; deliberate pauses remain deliberate.

Resource order and shared donor fallback are retained. A loaded, repeatedly absent owned container may be retired as unavailable, never reported as an inventory pickup. Tests cover simultaneous restocks, return freshness, admission acknowledgements, cancellation and protocol compatibility. Physical flight and inventory behavior require gameplay testing.
