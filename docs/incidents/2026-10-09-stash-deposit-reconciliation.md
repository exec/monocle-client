# Deposit verification and reopen barriers

A pending deposit timeout without retained source, destination and cursor evidence cannot distinguish a rejected click from missing confirmation. Capture authoritative player inventory and the exact source index before issuing the move.

Bounded same-chest reopening establishes a new server ordering barrier. Retry requires a different accepted menu, exact cargo conservation, empty cursor and compatible destination evidence. Vanilla cursor return may relocate only the exact kit into a previously empty slot; unrelated cargo changes remain unsafe.

A confirmed destination receipt completes the move once. Missing inventory without destination proof remains uncertain, including possible hopper drainage. Restart must not blindly replay pending intent. Structured diagnostics retain unchanged-count responses as well as gains.
