# Shared restocking under changing conditions

Shared supplies use the donor's advertised placed shulker. Ender inventory remains private; the donor retrieves and later recovers its own container. Visitors transfer matching contents without claiming the container.

Attempts expire and release their donor selection. Removed advertisements clear travel targets. Old issued-drop receipts retain reconciliation, while new shared-container requests avoid creating throw transactions. Matching capabilities are required.

Container protection follows real containers, footing and drops rather than reserving empty space. Repeated loaded absence can mark supplies unavailable and retry; unloaded terrain or a visible drop cannot. Accidental crew pickups become shared inventory rather than creating an indefinite return rendezvous.
