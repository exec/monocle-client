# Crew rejoin and prediction waits

Off-duty readiness must use the worker's current loaded chunk, while preserving server, dimension, player and supply-recovery boundaries. A stale work origin must not create a circular lane-restoration wait. Revisioned incremental admission lets existing peers continue without resetting their execution or outstanding acknowledgements.

Returning workers reconstruct nearby owned paving verification even without local placement history. Prediction probes are rate-limited and never count as server confirmation. Boat removal is limited to the current work or supply area and excludes the worker's own vehicle.

Regression coverage includes readiness, repair-window ownership, prediction ages, boat targets and authenticated leave/rejoin messages. Physical placement and rejoining still need gameplay validation.
