# Returning-worker verification gaps

A returning worker can land ahead of unfinished work assigned during a lane transition. Replaceable-only paving repair cannot resolve excavation or incorrect solid paving behind that landing point.

Recovery uses fresh host checkpoints and full row verification filtered to the worker's actual duties. Only the responsible worker reanchors logical work inside a bounded nearby window. Physical position, peer duties, supply recovery and material protections remain intact; pending inventory or block acknowledgements prevent repair.

Diagnostics identify the first global and owned verification blocker. Tests distinguish owned gaps from resolved peers and stale checkpoints. A prolonged stall alone is not proof of an irrecoverable deadlock.
